# Application form checklist

Run through this when the user pastes a form or a review page before Submit.

## Autofill damage (Workday, iCIMS, Oracle parse the resume and guess)
- [ ] **Work experience → Role Description** contains only that job's bullets. Autofill often dumps the whole Projects section into the last job. That reads as "built a distributed database during my retail internship": fix before certifying.
- [ ] **Company / title / dates** match the resume exactly (Co., Ltd. vs Co., Ltd; month + year).
- [ ] **Education → Field of study** matches the degree on the resume (autofill picks the closest dropdown, e.g. "Management Information Systems" for an E-Commerce degree).
- [ ] **Education → From / To** filled in; "To" is the expected graduation (e.g. 12/2027).
- [ ] **Skills** tags: remove any you couldn't talk about for 2 minutes.
- [ ] **Resume file** is the tailored, neutrally named PDF, not an old one.

## Questions that must be answered truthfully
- [ ] Legally authorized to work in the US? (students on F-1 doing an internship via CPT: Yes)
- [ ] Will you now or in the future require sponsorship? Answer what is true for the user. Never "No" to get past a filter.
- [ ] Graduation date, degree level, program dates / availability.
- [ ] Prior applications / previous employee / referral fields.

## Voluntary / EEO
- [ ] Gender, ethnicity, veteran, disability: voluntary. Confirm the choices are the user's own; "Decline to self-identify" is always fine.

## Before Submit
- [ ] Not a duplicate: check "My Applications" on that company's portal.
- [ ] Company-level limits respected (e.g. "2 applications per cycle across affiliates", "3 per 30 days").
- [ ] The certification checkbox ("facts are true and complete") is only ticked after the items above are fixed.

## Free-text answers
- **Why this company / role:** one concrete link between the user's real work and what this team builds, one real number, one sentence on what they want to learn there. ~120 words unless a limit is given.
- **How did you hear about us:** pick the true source (job board / referral / event). If "Other", say which list or site.
- **Links:** LinkedIn and GitHub only if the profiles are ready to be read.
